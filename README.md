# Ironclad

An idle tower defence for iPhone and iPad by Rushing Technologies, where the tower is an armoured train crossing the
frontier. Unity 6000.0.85f1, URP.

- Design: `docs/DESIGN.md`.
- Rules without Unity: `Assets/Scripts/Core`, tested by `Tools/core-test.sh`.
- Free models only (CC0 first, CC BY credited in `CREDITS.md` and in the game).
